# Sooner Response Photography

Professional public safety photography portfolio site for Oklahoma first responders.

**Capturing Heroes Across Oklahoma**

## Pages
- `index.html` — Home / Hero
- `gallery.html` — Masonry photo gallery with lightbox
- `services.html` — Photography services offered
- `about.html` — About + testimonial
- `contact.html` — Contact form (Formspree)

## Tech
- Tailwind CSS (CDN)
- Vanilla JS
- Font Awesome
- Formspree for contact form
- Google Analytics (GA4)

## Setup
1. Upload all files to a public GitHub repository
2. Enable GitHub Pages (Settings → Pages → Deploy from main)
3. Replace any placeholder image links in `script.js` with your direct ImgBB links
4. Keep `favicon.ico` in the root

## Notes
- Mobile hamburger menu included
- Back-to-top button
- Fully responsive
- SEO meta tags + Open Graph ready
